راهنمای ساخت (نسخه‌ی ویندوز) — تکنوکالا
=========================================
ساختار این فایل:
  src/        کد برنامه (فایل‌های جدا)           build.py   ساخت فایل کامل برنامه
  dist/       برنامه‌ی ساخته‌شده (app.html)       tests/     تست‌های خودکار
  desktop/    پوسته‌ی ویندوز (Electron)

ساخت برنامه‌ی ویندوز (نیاز به Node.js):
  1) داخل پوشه‌ی desktop:   npm install
  2) اجرای آزمایشی:         npm start
  3) ساخت نصب‌کننده:        npm run dist      (خروجی در desktop\dist)

اگر برنامه‌ی src را تغییر دادید، ابتدا در پوشه‌ی اصلی «python build.py» را اجرا کنید (dist\app.html به‌روز می‌شود)،
سپس مراحل بالا؛ مرحله‌ی «npm start / npm run dist» خودکار آن را داخل desktop کپی می‌کند.
شماره‌ی نسخه فقط در src\VERSION است.
